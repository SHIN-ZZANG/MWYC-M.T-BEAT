    라운드 구성
    • 단어 수 — 그 라운드에 나올 단어 종류. 넣은 단어 중에서 무작위로 고릅니다.
    • 카드 표시 — 라운드마다 카드 8장을 어떻게 보여 줄지 정합니다. 카드는 세 종류입니다.
      • 단어 — 글자만 크게
      • 사진+단어 — 사진 밑에 이름
      • 사진만 — 이름 없이 사진만 (얼굴만 보고 말하기)
    • 단어 · 사진+단어 를 고르면 8장 모두 그 종류로 나옵니다.
    • 섞기를 고르면 세 종류를 몇 장씩 낼지 직접 정합니다. 합이 8장이어야 하고, 어느 자리에 무엇이 올지는 매번 무작위입니다.
      • 예) 3 / 3 / 2 → 글자 3장 · 사진+이름 3장 · 사진만 2장
      • 예) 0 / 0 / 8 → 8장 모두 사진만 (사진만 라운드)
    • 사진이 없는 단어는 이모지로, 그것도 없으면 글자로 나옵니다.
    • 추천 구성 — 단어 → 사진+단어 → 섞기 → 사진만. 단어 수는 3개에서 시작해 1개씩 늘어납니다.
    라운드단어 수카드 표시섞기 장수 (합 8장)

    카드 하나에 주어지는 시간 기준입니다. 단어가 길수록 실제로는 더 어렵습니다.

    단어

    • 단어는 2~50개 넣을 수 있습니다. 짧은 단어일수록 빠른 박자에서도 말하기 쉽습니다.
    • 라운드마다 카드 8장을 고른 단어로 가능한 한 고르게 채웁니다 (3종류면 3·3·2번, 4종류 이상이면 최대 2번). 같은 단어가 바로 연달아 나오지는 않습니다. 자동 구성은 첫 라운드 4종류에서 라운드마다 1개씩 늘어납니다.
    • 카드 그림은 단어마다 정합니다. 사진을 올리면 사진, 아니면 이모지, 둘 다 없으면 단어 글자가 크게 나옵니다. 한 세트 안에서 섞어 써도 됩니다. Windows 는 Win + . 으로 이모지를 넣을 수 있습니다.
    • 마지막 칸에서 Enter 를 누르면 새 줄이 추가됩니다.

    📷 사진 칸을 눌러 사진을 고르세요. 가운데 기준으로 정사각형으로 잘려 512px 로 줄여 저장됩니다. 사진을 넣으면 이모지 칸은 쓰이지 않고, ✕ 로 사진을 빼면 다시 이모지를 쓸 수 있습니다. 영상으로 올릴 거라면 직접 찍은 사진이나 무료 이미지를 쓰세요 (저작권).
